Bài thực hành tìm hiểu cách hoạt động của DNS và các hình thức tấn công DNS Spoofing, DNS Cache Poisoning trong mạng ảo cô lập.

Môi trường sử dụng: VirtualBox, pfSense, Ubuntu Server, Kali Linux, BIND9 và Scapy.

Nội dung thực hiện:
- Cấu hình DNS Server và kiểm tra phân giải tên miền.
- Thử nghiệm chuyển hướng tên miền bằng file hosts.
- Mô phỏng DNS Spoofing và DNS Cache Poisoning.
- Kiểm tra truy vấn DNS, xóa cache và khôi phục cấu hình.
